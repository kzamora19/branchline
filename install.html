Install Branchline

Branchline installs like any other app: its own icon, its own window, no browser bar.

Open Branchline

Android phone or tablet (Chrome)

  1. Open this page in Chrome.
  2. Tap Install Branchline above, or the ⋮ menu → Install app / Add to Home screen.
  3. Open Branchline from your home screen.

iPhone or iPad (Safari)

  1. Open this page in Safari (not another browser).
  2. Tap the Share button → Add to Home Screen → Add.

Windows (Edge or Chrome)

  1. Open this page in Edge or Chrome.
  2. Click Install Branchline above, or the install icon at the right of the address bar.
  3. Branchline appears in the Start menu and can be pinned to the taskbar.

Ubuntu / Linux (Chrome, Chromium or Edge)

  1. Open this page in Chrome, Chromium or Edge. (The Firefox and Snap-packaged Firefox builds cannot install web apps.)
  2. Click Install Branchline above, or the install icon in the address bar. If it is missing: ⋮ menu → Cast, save and share → Install page as app.
  3. Find Branchline in your applications menu.

Sign in with the login ID and temporary password from your invite, then change your password. Branchline needs an internet connection to load sales data.
