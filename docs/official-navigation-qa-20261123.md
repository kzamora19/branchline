## Explicit test limits

- The MegaFrame/MegaFlyer nav screenshots use a **no-ticket** editor-free launcher to prove fail-closed behavior; no private editor appears in those screenshots. Private editor, revocation and cloud behavior have earlier independently passing tests but need a *new exact combined headed hosted session* on the authoritative preview domain before production.
- The PTG CI screenshots use a **synthetic account** and network-intercepted PTG auth responses, not real users or production credentials.
- The outer Studio launcher must not inject global navigation into the protected opaque-origin iframe. Consequently a Studio editor's internal mobile workspace drawer cannot be introspected/closed directly by its outer app rail; the overlay obscures it but exact two-drawer mutual exclusion across the boundary remains an acceptance item.
- Unverified: Windows actual WebView2 installer/upgrades and rollback, old PWA/project data migration, physical printer alignment and image/PDF export on real devices, live Google Drive OAuth and cloud backup/recovery under real PTG sessions.
- Official icons are source-matched, but small-scale accessibility/legibility should be checked on devices.

## Release rule

Keep all four PRs draft until the authentic hosted integration + device/print/Drive/PWA acceptance and an explicitly approved release order. Do not silently publish public Studio editor content, alter production database policies, replace existing installer downloads, or modify the already-live Promotion/Event popup.
